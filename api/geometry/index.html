    Geometry¶

    The geometry pipeline from raw meshes to the output mesh, in three modules:

    1. Surface sampling (surface_sampling.py): discretizes test-surface faces into evenly spaced points with outward-facing normals, using grid_step and a coplanarity tolerance; also computes the edge_taper weights. Used by preprocessing.
    2. Voxelization (voxelization.py): converts the max-volume mesh into a dense cubic boolean grid at the configured voxel_size. Used by preprocessing.
    3. Meshing (meshing.py): removes voxel clusters smaller than min_voxels and converts the carved voxel mask back into a triangle mesh, either as cubic voxel faces or via SDF smoothing + marching cubes + Taubin polishing. Used by exporting.

    Surface sampling¶

    urbansolarcarver.surface_sampling ¶

    UrbanSolarCarver: test-surface sampling

    Samples the test surfaces into the points and normals that rays start from, and the analysis-mesh quads that show one face per sample point. Used by preprocessing.

    Pipeline entry point

    sample_surface(insolation_mesh, settings) discretize_surface_with_normals with the preprocessing settings; raises when no sample points are produced.

    Public API

    sample_planar_surface(mesh, sample_step=1.0, include_boundary=True, edge_taper=0.0) Sample one planar connected component on a regular grid. Returns points, normals, analysis-mesh quads (vertices + faces), and edge-taper weights.

    discretize_surface_with_normals(mesh, sample_step=1.0, coplanarity_tol_deg=5.0, edge_taper=0.0) Split the mesh into connected components, sample each planar one, and return points, normals, an AnalysisMesh, weights, and taper statistics.

    AnalysisMesh Quad mesh with one face per sample point; serialised to analysis_mesh.json.

    Internal helpers

    plane_frame(surface_normal) Orthonormal in-plane basis for planar sampling.

    _mesh_boundary_loops(mesh), _sample_boundary_edges(polygon, ...) Boundary extraction and extra samples along boundary edges.

    Data types and units
    • Points and normals: np.ndarray, shape (N, 3), world units.

    plane_frame(surface_normal) ¶

    Return two orthonormal vectors spanning the plane orthogonal to surface_normal.

    Parameters:

    Name Type Description Default
    surface_normal (3,) array_like

    Plane normal (need not be unit length).

    		 required

    Returns:

    Type Description
    axis_u, axis_v : (3,) np.ndarray

    Unit vectors with cross(axis_u, axis_v) equal to the unit normal, so (axis_u, axis_v, normal) is a right-handed frame.

    Raises:

    Type Description
    ValueError

    If surface_normal has near-zero length.
    Notes
    • The normal is normalized internally.
    • The reference axis is X, or Y when the normal is within about 26 deg of X, so the cross product never degenerates.
    • The result depends only on the normal, so panels with the same normal get the same frame (up to the sign of axis_u when the normal is negated).
    • Used by sample_planar_surface to build a local 2D sampling frame.

    Type Description

    voxelize_solid_warp(vertices, faces, grid_origin, voxel_size, resolution, device, *, centre_only=False, span_min=None, span_max=None) ¶

    Solid-voxelize a triangle mesh by parity ray casting along x, y and z against a Warp BVH (bounding volume hierarchy).

    A voxel is occupied when at least 2 of the 3 axis parity tests find its centre inside (a majority vote, so one axis confused by a small hole or a grazing ray does not decide the result; trimesh's orthographic fill uses the same idea), or when the mesh surface passes through it. Runs on CUDA or the Warp CPU device; voxelization.py uses trimesh's slower rasterize-and-fill only when this returns None, and lets anything it raises propagate.

    With centre_only the surface-through rule is left out: a voxel is occupied only when its centre is inside (the context rule). span_min and span_max (same frame as grid_origin) move the start and end of the per-axis rays out to them where they lie beyond the grid, so a mesh larger than the grid keeps a correct parity inside it; votes are still written only for cells of the grid. The defaults give the maximum volume's voxelization unchanged.

    Returns:

    Type Description
    ndarray | None

    (resolution, resolution, resolution) bool occupancy array, or None when the Warp backend is unavailable on device.

    Raises:

    Type Description
    ValueError

    If the mesh has no vertices or no faces.

    Meshing¶

    urbansolarcarver.meshing ¶

    UrbanSolarCarver: meshing

    Cleans the carved occupancy grid and turns it into the output mesh. Used by exporting.

    Overview

    Two meshing modes are supported:

    1) Cubic (apply_smoothing == False) - Clean the binary grid: drop small connected components, then drop occupied voxels with fewer than 2 occupied neighbours in their 3×3×3 neighbourhood. - Triangulate with the shared-vertex cubic mesher (_cubic_mesh_from_occupancy).

    2) Smoothed SDF (apply_smoothing == True) - Convert occupancy to a signed distance field (SDF) in voxel units. - Light Gaussian blur, then edge-preserving Perona–Malik diffusion; the result is kept only within 2 voxels of the zero level. - Pick an iso value that preserves the original inside volume. - Extract a surface with marching cubes (scikit-image). - Optionally run a short Taubin polish (0 to 6 iterations) after cleanup.

    Pipeline entry point

    finalize_mesh(carved_grid, grid_origin, settings, voxel_size) Clean the carved grid and mesh it with the cubic or smoothed path.

    Public API

    prune_voxels(voxels, min_voxels) Remove 26-connected components smaller than min_voxels.

    prune_voxels_morph(voxels, min_voxels) Cleanup for the cubic path: component prune, then the neighbour-count filter described above. Only removes voxels; no erosion or closing.

    mesh_from_voxels(voxels, min_corner, voxel_size) Build a blocky mesh from the binary grid. Returns an unprocessed Trimesh.

    mesh_from_voxels_smoothed(voxels, min_corner, voxel_size) Build a smooth mesh by contouring a smoothed SDF with marching cubes. Uses a volume-matched iso to avoid systematic thinning.

    cleanup_mesh(mesh, min_face_count=100, light=False) Fix winding/normals (unless light), weld vertices, drop small fragments.

    polish_mesh_taubin(mesh, iters=2) Optional Taubin polish after the SDF + marching cubes path, at most 6 iterations.

    Internal helpers

    _cubic_mesh_from_occupancy(voxels, min_corner, voxel_size) Vertex and face arrays for the cubic mesher.

    _voxel_presmooth(field_bool) SDF build + Gaussian + narrow-band Perona–Malik diffusion.

    _pm_anisotropic_diffuse(sdf, iters, k, tau) Edge-preserving diffusion stepper used by _voxel_presmooth.

    _volume_matched_threshold(sdf, target_inside_voxels) Iso selection that matches the original inside count.

    _median_edge_length(m) Median of unique edge lengths; used to normalize the Taubin polish.

    Data types and units
    • Voxel grids: torch.Tensor, shape (D, D, D), uint8/bool, 1 = inside.
    • Meshes: trimesh.Trimesh in world coordinates.
    • voxel_size is in world units and is passed to marching cubes as the grid spacing.
    Notes
    • The cubic path gives a blocky "voxel look" that is stable between runs. It applies no erosion, so thin volumes are kept.
    • The smoothed path operates in SDF space, not on the triangle mesh. This removes terracing while keeping the overall form.
    • The Taubin step is short and optional. Heavy smoothing belongs in SDF space, not on the mesh.

    prune_voxels_morph(voxels, min_voxels) ¶

    Light cleanup for the cubic (unsmoothed) path.

    Steps
    1. Remove connected components (26-connectivity) with fewer than min_voxels voxels.
    2. Remove occupied voxels whose 3×3×3 neighbourhood (including the voxel itself) holds fewer than 3 occupied voxels, i.e. voxels with 0 or 1 occupied neighbours. This drops isolated specks and one-voxel spurs.

    Only removes voxels, never adds them: adding would undo carving.

    Name Type Description Default

    Size threshold; components with fewer voxels are removed.

    		 required

    Binary occupancy on the same device as voxels.

    polish_mesh_taubin(mesh, iters=2) ¶

    Apply a short Taubin smoothing pass to remove small ripples.

    Parameters:

    Name Type Description Default
    mesh Trimesh

    Modified in place.

    		 required
    iters int

    Number of trimesh Taubin steps, capped at 6. trimesh alternates steps (even steps shrink, odd steps inflate), so even values give complete shrink/inflate pairs. If 0 or less, the mesh is returned unchanged.

    		 2

    Returns:

    Name Type Description
    mesh Trimesh

    The same object, smoothed, with degenerate faces removed.
    Notes
    • Uses fixed parameters λ = 0.28 and ν = 0.31 (trimesh's sign convention; μ = −0.31 in Taubin's notation).
    • Vertices are centred and scaled to unit median edge length during smoothing, then restored.
    • Intended only after the SDF + marching cubes path. Keep the iteration count small to avoid shape drift.
