# Inspect Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third workspace, Inspect, that draws the test surfaces two-sided with their normals, flips a surface on click (staged, then saved), and lists a short summary of every input mesh file.

**Architecture:** A new service module (`local_web_service/inspection.py`) reads each stored file as `io.load_mesh` gives it, labels its edge-connected surfaces, and serves summaries and a binary geometry per test surface file (triangles with a surface number each). A save writes the turned file in its own format, checks that `load_mesh` keeps the turns, keeps the original once, and rebuilds the joined files as an upload would (no "changed in the folder" notice). The app adds `"inspect"` to the workspace switch, a new view layer drawn two-sided with arrows, a click callback on the scene, and a floating Files panel.

**Tech Stack:** Python 3 / FastAPI / trimesh / numpy (service); React 19 + TypeScript + three.js, vitest (app).

**Spec:** `docs/superpowers/specs/2026-10-27-inspect-design.md` (commit `e6bcc69`).

## Global Constraints

- Flips only for test surface files. Nothing else in a file is changed; no other role is written.
- A flip turns a whole surface: the triangles connected by shared edges in the mesh `load_mesh(path)` returns (with `fix_normals=True`, as the engine reads test surfaces).
- A test surface file whose loaded mesh is watertight as a whole cannot be flipped (`load_mesh` calls `fix_normals(multibody=True)` on it, which turns every closed body outward again). Refuse with 422 and the message `This file is closed as a whole, and the loader always turns its bodies outward, so its surfaces cannot be flipped.`
- A save writes nothing unless `load_mesh` of the written file gives the same triangle count and every triangle's normal within 1e-6 of the expected one (turned surfaces negated), in face order.
- The kept original lives at `inputs/originals/test_surfaces/<file name>`, written once (before the first save), removed by Restore original, by an upload that replaces the file, and when the stored file is discarded.
- A save or restore has the effects of an upload through the app: the joined files of every criterion and study that lists the file are built again, its triangle count and `stored_files` record are renewed; it adds no `changed_files` notice and does not raise `inputs_revision`.
- Save and restore are refused with 409 while a run of the project is active (as uploads: `refuse_while_running`). Reading the inspection is allowed during a run.
- Georeferenced coordinates: the geometry is sent as float32 relative to a float64 `frame` (as `simulation.study_values`); written files keep full precision (OBJ with at least 10 decimals, PLY as float64 via `io.save_mesh`).
- "Far from zero" means a bounds corner more than 10,000 m from the file's origin; the app then adds `Georeferenced coordinates, about {distance} km from 0.`
- Texts: plain sentences, no em dashes. UI names: "Inspect", "Files", "Arrows", "Flip mode", "Flip all", "Save", "Discard", "Restore original".
- Tests per tier in `CLAUDE.md` / `docs/testing.md`; in a worktree run Python as `PYTHONPATH=src "D:/RESEARCH_CENTER/ACTIVE_PROJECTS/RSBenvelope_generation/urbanSolarCarver/.venv/Scripts/python.exe" -m pytest ...`. `npm run build` before the commit tier; the packaging test checks `ui_static`.

## Review Focus

1. A test surface file closed as a whole (one box): every click says why it cannot flip, Save is never offered, the service refuses 422. Pinned in Task 2 and Task 5.
2. Two panels whose edges coincide in position but carry different vertex normals in an OBJ (Rhino exports panels this way): they are two surfaces before and after a save; flipping one leaves the other. Pinned in Task 2.
3. Georeferenced coordinates (x around 4.5e6): the geometry decodes to the right place within 1 mm, and a save keeps coordinates to 1e-6 m. Pinned in Task 1 and Task 2.
4. An OBJ with quads or n-gons: the triangle count after a save equals the loaded count, and the reload check passes. Pinned in Task 2.
5. Save while a Design run or a simulation of the project is going: the app shows Save disabled with "A run is in progress", the service answers 409, nothing is written. Pinned in Task 2 and Task 5.

  - `inspect_file(path: Path, role: str) -> FileInspection` (a frozen dataclass: `mesh: trimesh.Trimesh`, `surface_of_face: np.ndarray` int32 per face (test surfaces; zeros otherwise), `summary` fields as above). Cached by `(str(path), size, mtime_ns)`.

- Routes: `GET /api/projects/{name}/inspect` -> `InspectReply`; `GET /api/projects/{name}/inspect/test_surfaces/{file_name}/geometry` -> `application/octet-stream`, 404 for an unknown file.
