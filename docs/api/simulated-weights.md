# Simulated Weights

Simulated benefit weights: an ISO 13790 Annex C hourly thermal model
("5R1C") plus perturbation attribution, producing the hourly `benefit` /
`harm` series consumed by benefit mode's `simulated_weights_path`. See
[Carving Modes](../modes.md#simulated-weights) for the user-level
workflow and Tutorial 5 for a walkthrough.
